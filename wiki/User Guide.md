## 💰 収支管理

### 💸 支出の記録

#### 基本的な支出入力

1. **新規支出の追加**
   ```
   ホーム画面 → [+] ボタン → 支出
   ```

2. **必須項目の入力**
   - **金額**: 支出額を入力
   - **カテゴリ**: 適切なカテゴリを選択
   - **日付**: 支出日を選択（デフォルト：今日）

3. **任意項目の入力**
   - **メモ**: 詳細説明（例：「スーパーでの買い物」）
   - **サブカテゴリ**: より詳細な分類

#### 📋 支出カテゴリ一覧

| カテゴリ | 説明 | 例 |
|---------|------|-----|
| 🍽️ **食費** | 食事・飲料 | 外食、スーパー、コンビニ |
| 🏠 **住居費** | 住まい関連 | 家賃、光熱費、インターネット |
| 🚗 **交通費** | 移動費用 | 電車、バス、ガソリン、駐車場 |
| 🛍️ **買い物** | 生活用品 | 衣類、日用品、家電 |
| 🎯 **娯楽費** | エンターテイメント | 映画、ゲーム、旅行 |
| 💊 **医療費** | 健康関連 | 病院、薬、保険 |
| 📚 **教育費** | 学習・成長 | 本、セミナー、習い事 |
| 🎁 **その他** | 上記以外 | ギフト、寄付、雑費 |

#### 🔄 支出の編集・削除

1. **支出一覧から編集**
   ```
   ホーム画面 → 支出一覧 → 対象項目をタップ
   ```

2. **編集操作**
   - ✏️ **編集**: 内容の修正
   - 🗑️ **削除**: データの完全削除
   - 📋 **複製**: 似た支出の簡単入力

### 💵 収入の記録

#### 基本的な収入入力

1. **新規収入の追加**
   ```
   ホーム画面 → [+] ボタン → 収入
   ```

2. **収入情報の入力**
   - **金額**: 収入額
   - **カテゴリ**: 収入の種類
   - **日付**: 収入日
   - **メモ**: 詳細（任意）

#### 💰 収入カテゴリ

| カテゴリ | 説明 | 例 |
|---------|------|-----|
| 💼 **給与** | 本業の収入 | 基本給、賞与、残業代 |
| 💻 **副業** | 副収入 | フリーランス、アルバイト |
| 📈 **投資** | 投資収益 | 配当、売却益、利息 |
| 🎁 **その他** | 上記以外 | ギフト、還付金、臨時収入 |

## 📊 分析機能

### 📈 ダッシュボード

ホーム画面のダッシュボードでは、以下の情報を一目で確認できます：

#### 💳 残高表示
```
今月の収支
├── 収入: ¥350,000
├── 支出: ¥280,000
└── 残高: ¥70,000 (+20%↗️)
```

#### 📊 グラフ表示
- **円グラフ**: カテゴリ別支出割合
- **棒グラフ**: 月次推移
- **線グラフ**: 収支トレンド

### 📋 月次レポート

詳細な月次分析を確認できます：

1. **アクセス方法**
   ```
   ホーム画面 → 📊 レポート → 月次レポート
   ```

2. **表示内容**
   - 📅 **月別収支**: 選択月の詳細データ
   - 🏆 **カテゴリランキング**: 支出の多いカテゴリ
   - 📈 **トレンド分析**: 前月比較
   - 💡 **改善提案**: AIによる節約アドバイス

#### 📊 グラフの種類

| グラフ | 用途 | 詳細 |
|--------|------|------|
| 🥧 **円グラフ** | カテゴリ構成比 | 支出の内訳を視覚化 |
| 📊 **棒グラフ** | 月次比較 | 過去12ヶ月の推移 |
| 📈 **線グラフ** | 収支トレンド | 収入・支出の変化 |
| 📋 **表形式** | 詳細データ | 数値での正確な確認 |

### 🎯 予算管理

#### 予算設定

1. **月次予算の設定**
   ```
   設定 → 予算管理 → 月次予算設定
   ```

2. **カテゴリ別予算**
   - 各カテゴリに個別予算を設定
   - 使用率をリアルタイム表示
   - 予算超過時のアラート

#### 📊 予算の可視化

```
カテゴリ別予算使用状況
├── 食費: ¥45,000 / ¥50,000 (90%) 🟡
├── 住居費: ¥80,000 / ¥80,000 (100%) 🔴
├── 交通費: ¥8,000 / ¥15,000 (53%) 🟢
└── 娯楽費: ¥12,000 / ¥20,000 (60%) 🟢
```

## 🔧 設定と管理

### ⚙️ アプリ設定

#### 基本設定

1. **通貨設定**
   ```
   設定 → 基本設定 → 通貨
   ```
   - 主要通貨への対応
   - 表示形式のカスタマイズ

2. **言語設定**
   ```
   設定 → 基本設定 → 言語
   ```
   - 日本語（デフォルト）
   - 英語（予定）

#### 📊 データ管理

1. **バックアップ**
   ```
   設定 → データ管理 → バックアップ
   ```
   - **自動バックアップ**: 定期的な自動保存
   - **手動バックアップ**: 任意のタイミングで保存
   - **バックアップ先**: ローカルストレージ

2. **データエクスポート**
   ```
   設定 → データ管理 → エクスポート
   ```
   - **CSV形式**: Excel等で開けるファイル
   - **JSON形式**: 詳細データ形式
   - **期間指定**: 必要な期間のみ抽出

#### 🔒 セキュリティ設定

1. **アプリロック**
   ```
   設定 → セキュリティ → アプリロック
   ```
   - **PIN設定**: 4〜6桁の数字
   - **指紋認証**: 対応端末での生体認証
   - **自動ロック**: 指定時間後の自動ロック

2. **データ暗号化**
   - すべてのデータは自動的に暗号化
   - ローカル保存でプライバシー保護

### 📤 データの共有・エクスポート

#### CSV エクスポート

1. **エクスポート手順**
   ```
   設定 → データ管理 → CSVエクスポート
   ```

2. **エクスポート内容**
   - 全期間または指定期間のデータ
   - カテゴリ別またはすべてのデータ
   - 収入・支出の分類指定

3. **出力ファイル例**
   ```csv
   日付,カテゴリ,金額,メモ,タイプ
   2025-06-22,食費,1200,ランチ代,支出
   2025-06-22,給与,250000,基本給,収入
   ```

#### データの復元

1. **バックアップからの復元**
   ```
   設定 → データ管理 → 復元
   ```

2. **注意事項**
   - 復元前に現在のデータをバックアップ
   - 復元は既存データを上書き
   - 操作は慎重に実行

## 🆘 トラブルシューティング

### 🐛 よくある問題と解決方法

#### アプリが起動しない

**症状**: アプリをタップしても起動しない

**解決方法**:
1. **端末の再起動**
   - 端末を一度再起動
   - メモリの解放効果

2. **アプリの再インストール**
   - データをバックアップ
   - アプリをアンインストール
   - 最新版を再インストール

#### データが表示されない

**症状**: 入力したデータが表示されない

**解決方法**:
1. **アプリの再起動**
   - アプリを完全に終了
   - 再度起動してデータを確認

2. **データベースの確認**
   ```
   設定 → データ管理 → データベース確認
   ```

#### 動作が重い

**症状**: アプリの動作が遅い

**解決方法**:
1. **不要データの削除**
   - 古いデータの定期削除
   - バックアップ後に不要な履歴を削除

2. **アプリの最適化**
   ```
   設定 → パフォーマンス → 最適化実行
   ```
