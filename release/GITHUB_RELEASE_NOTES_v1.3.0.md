# 🎨 MoneyG Finance App v1.3.0 - テーマカスタマイズ大型アップデート

## 📱 ダウンロード

**Android**: [MoneyG-Android-v1.3.0-updated.zip](https://github.com/paraccoli/flutter_finance_app/releases/download/v1.3.0/MoneyG-Android-v1.3.0-updated.zip)

## 🎭 主な新機能

### 🎨 テーマシステムの大刷新

- **9つのプリセットテーマ**: ライト、ダーク、コズミック、コスモス、ネイチャー、サンセット、オーシャン、サイバー、ピンクハート
- **カスタムテーマ作成**: 3色カラーシステム（プライマリ、セカンダリ、アクセント）
- **リアルタイムプレビュー**: 変更内容を即座に確認
- **テーマ管理**: 編集、複製、削除機能

### 💎 UI/UXの向上

- **21色カラーパレット**: プリセットまたはカスタムカラー選択
- **フォントサイズ調整**: 10px〜20pxのスライダー調整
- **UI要素カスタマイズ**: 残高表示、カテゴリアイコン、グラデーション、アニメーション設定
- **背景画像対応**: コスモステーマで宇宙背景を実装

## 🛠️ 技術的改善

- **新規追加ファイル**: `CustomThemeSettings`、`CustomThemeCreatorScreen`、`CustomThemeManagerScreen`、`BackgroundWidget`
- **ThemeViewModel拡張**: カスタムテーマ保存・管理機能
- **データ永続化**: 自動保存とアプリ再起動時の設定復元
- **コードアーキテクチャ改善**: 新しいテーマタイプとカスタムテーマ対応

## 📦 ファイル情報

- **APKサイズ**: 27.8MB
- **対象プラットフォーム**: Android
- **最小Androidバージョン**: API 21 (Android 5.0)
- **ビルド番号**: 1.3.0+1

## 🚀 使い方

1. **設定 → テーマ選択**からプリセットテーマを選択
2. **設定 → カスタムテーマ作成**で新しいテーマを作成
3. **設定 → カスタムテーマ管理**で既存テーマを管理
4. プレビューを見ながら直感的にカスタマイズ
