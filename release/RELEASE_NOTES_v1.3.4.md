MoneyG - Release v1.3.4

リリース日: 2025-11-10

主な変更点

- 不具合修正: 報酬広告（Rewarded Ad）視聴後に一時的プレミアムが有効にならない問題を修正しました（広告のライフサイクルでの競合を解消）。
- 機能変更: 無料ユーザー向けに「広告非表示」「カスタムテーマ作成」「データバックアップ」をプレミアム機能としてロックしました。設定画面とテーマ画面で利用不可時に案内ダイアログを表示します。
- 表示改善: 収入／支出画面の初期表示期間を「今月（1日00:00:00 〜 今月末23:59:59）」に変更しました。
- 例外修正: 日付範囲ピッカーの初期値が未来日となってクラッシュする問題を防ぐため、日付選択ロジックを堅牢化しました。
- その他: Android の広告ユニットを本番 ID に差し替え（iOS は未設定）、バージョンを `1.3.4+1` に更新。

ビルド

- AAB: `build\app\outputs\bundle\release\app-release.aab` を作成しました（この処理はローカルビルドで行っています）。

注意事項

- Google Play の審査に関連するメタ情報（App content / 金融サービスの申告）について、以前に却下が発生しているため、公開前に Play Console の「アプリの内容」設定を見直してください。
- iOS 向けに広告ユニット ID を変更する場合は別途 iOS のユニット ID をご提供ください。

変更履歴・開発者メモ

- ブランチ: `release/v1.3.4` を作成して変更をプッシュすることを推奨します（現在は `release/v1.3.3` 上の作業）。
