# Money:G v1.3.2 リリースノート

## リリース日: 2025年7月11日

### 新機能

#### MoneyGレガシーCSVサポート

- **MoneyG CSVファイル完全対応**
  - 「支出のみ」「収入のみ」「全データ」の3つのエクスポート形式をすべてサポート
  - 自動フォーマット検出機能により、ファイル形式を自動判別
  - レガシーカテゴリの正確なマッピング（食費、買い物、給与など）

- **設定画面の機能拡張**
  - データ管理セクションにMoneyGデータインポート機能を追加
  - 直感的なUI設計で簡単なCSVインポート操作

### 重要なバグ修正

#### CSVインポートの修正
- **全データ形式のインポート問題を解決**
  - 支出データが負の値（例：-108.0）で記録されている場合に正しくインポートされない問題を修正
  - 収入・支出の判定ロジックを改善し、データ型に関係なく正確にインポート

#### データ処理の改善
- **エラーハンドリングの強化**
  - CSV解析時のエラー処理を改善
  - 不正なデータ行をスキップしつつ、有効なデータは確実にインポート

### 技術的改善

#### デバッグ機能の強化
- **詳細なデバッグ出力**
  - CSVインポート処理の各ステップを詳細に記録
  - カテゴリマッピングの結果を可視化
  - トラブルシューティングが容易になるログ出力

#### パフォーマンスの最適化
- **メモリ使用量の改善**
  - 大きなCSVファイルの処理効率を向上
  - バックグラウンド処理によるUI応答性の改善

### 対応形式

#### MoneyG CSVエクスポート形式
1. **支出のみ** (`expenses_*.csv`)
   - 形式: 日付,カテゴリ,金額,メモ
   - 対応カテゴリ: 食費、買い物、交通費、家賃、娯楽、健康・医療など

2. **収入のみ** (`incomes_*.csv`)
   - 形式: 日付,カテゴリ,金額,メモ
   - 対応カテゴリ: 給与、ボーナス、副業、投資など

3. **全データ** (`all_data_*.csv`)
   - 形式: 日付,タイプ,カテゴリ,金額,メモ
   - 収入・支出を一つのファイルで管理
   - 支出は負の値、収入は正の値で記録

### 使用方法

1. **設定** → **データ管理** → **MoneyGデータインポート**
2. インポートしたいCSVファイルを選択
3. プレビューでデータを確認
4. **インポート実行**で完了

### データ移行

MoneyG v1.2.xからv1.3.2への移行が非常に簡単になりました：
- 旧バージョンでエクスポートしたCSVファイルをそのまま使用可能
- カテゴリは自動的に新しい形式にマッピング
- データの整合性チェックにより重複インポートを防止

### 注意事項

- CSVインポート前に既存データのバックアップを推奨
- 大量データのインポート時は端末の空き容量を確認
- インポート後はデータの整合性確認を推奨

### インストール・アップデート手順

#### 新規インストールの場合
1. 下記のAPKファイルをダウンロード
2. Android端末にインストール
3. 初回セットアップを完了

#### 既存バージョンからのアップデートの場合

**通常のアップデート手順：**
1. 既存アプリの上にAPKファイルをインストール
2. データは自動的に引き継がれます

**アップデートでエラーが発生する場合：**
1. **事前準備**（重要）
   - 設定 → データ管理 → **完全バックアップ**を実行
   - または 設定 → データ管理 → **データエクスポート**で全データをCSV出力
2. **アプリの再インストール**
   - 既存のMoney:Gアプリをアンインストール
   - 最新版APK（v1.3.2）をインストール
3. **データ復元**
   - 設定 → データ管理 → **バックアップ復元**でJSONファイルを復元
   - または 設定 → データ管理 → **MoneyGデータインポート**でCSVファイルを復元

⚠️ **重要**: アンインストール前に必ずデータのバックアップまたはエクスポートを実行してください。バックアップなしでアンインストールするとデータが完全に失われます。
