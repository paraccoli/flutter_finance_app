# Money:G - Release v1.3.5

## 基本情報

- **リリース日**: 2025-11-15
- **バージョン**: 1.3.5
- **リリースタイプ**: パッチ

## 概要

v1.3.5 は、定期支出とプレミアム画面周りの不具合修正と小さな改善を含むパッチリリースです。

## 主な変更点

### 新機能
- なし（マイナー/パッチリリース）

### 改善・修正
- **定期支出のカテゴリ選択不具合修正**: カスタムカテゴリを作成して定期支出に割り当てた際に、保存後にデフォルトカテゴリ（例: 食費）に戻ってしまう問題を修正しました。`recurring_edit_screen.dart` 内でカテゴリを事前ロードすることで解決しました。
- **プレミアム関連 UI の整理**: 設定画面に同じ「プレミアム版にアップグレード」のエントリが重複して表示される問題を統一しました。`PremiumUpgradeScreen` を正規のアップグレード画面として採用し、重複する参照を整理しました。
- **設定画面の軽微な修正**: `SwitchListTile` のパラメータ更新等、静的解析で検出された細かな修正を適用しました。

### 重要なバグ修正
- 定期支出のカテゴリが正しく保存されない問題を修正しました（上記参照）。

### 技術的な変更
- 画面遷移の参照整理（`PremiumPurchaseScreen` の参照を `PremiumUpgradeScreen` に置換、不要ファイルの整理）。

## ユーザーへの影響

### 使い方の変更
- ユーザー操作の変更はありません。設定画面の「プレミアム」表示の重複が解消され、より一貫した導線になります。

### 注意事項
- 本リリースはデータベースのスキーマ変更を伴いませんが、念のためアップデート前にバックアップを推奨します（設定 → データ管理 → データのバックアップ）。

## アップデート手順

1. 既存アプリの上に最新版APKをインストールしてください。データは通常自動で引き継がれます。
2. 万一問題が発生した場合は、事前にバックアップを取り、必要に応じて再インストール後に復元してください。
