# 📝 MoneyG Finance App v1.3.1 - パッチ更新

## 🛠️ 緊急修正 (2025年7月8日)

### 🐛 重要なバグ修正

#### カスタムカテゴリ表示問題の修正
- **円グラフ表示**: カスタムカテゴリが「その他」として表示される問題を修正
- **支出検索画面**: 検索結果でカスタムカテゴリが正しく表示されない問題を修正
- **支出リスト**: カスタムカテゴリの名前、色、アイコンが正しく表示されるように修正

#### データベース整合性の改善
- **カテゴリ削除処理**: カスタムカテゴリ削除時のデータ整合性を改善
- **データマイグレーション**: データベースv5への自動アップグレード
- **削除済みカテゴリ**: 削除されたカテゴリを使用していたデータは「削除されたカテゴリ」として表示

### 🚀 技術的改善

#### ファイル構造の最適化
- **Expenseモデル拡張**: `customCategoryId`フィールドの追加
- **ExpenseViewModel改良**: カスタムカテゴリ対応統計メソッドの追加
- **ExpenseScreen更新**: 新しいカスタム円グラフウィジェットの実装
- **ExpenseSearchScreen修正**: カスタムカテゴリフィルタリング機能の追加

#### UI/UX の向上
- **円グラフ**: カスタムカテゴリ名と色が正しく表示
- **検索機能**: カスタムカテゴリでのフィルタリングが可能
- **リスト表示**: カスタムカテゴリのアイコンと色が表示
- **エラーハンドリング**: 削除されたカテゴリの適切な処理
