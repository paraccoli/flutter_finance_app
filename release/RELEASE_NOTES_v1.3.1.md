# 📝 MoneyG Finance App v1.3.1 - カスタムカテゴリ機能追加

## 📝 リリース概要

v1.3.1では、ユーザーからのリクエストが多かった**カスタムカテゴリ機能**を実装しました。これにより、既存のプリセットカテゴリに加えて、ユーザー独自のカテゴリを作成し、収入・支出の記録をより詳細に管理できるようになりました。

## 🆕 新機能

### 🏷️ カスタムカテゴリシステム

#### ✨ カテゴリ作成機能
- **無制限のカテゴリ作成**: 収入・支出それぞれで独自カテゴリを作成
- **カラーカスタマイズ**: 20色のプリセットカラーから選択
- **アイコンカスタマイズ**: カテゴリ別に整理された豊富なアイコンライブラリ
- **リアルタイムプレビュー**: 作成中のカテゴリを即座に確認

#### 🎨 視覚的カスタマイズ
- **カテゴリカラー**: 各カテゴリに固有の色を設定
- **Material Iconsライブラリ**: カテゴリごとに分類されたアイコン選択
  - 一般カテゴリ
  - 食事・飲食
  - 交通・移動
  - エンターテイメント
  - ショッピング
  - 健康・医療
  - ビジネス・仕事
  - 家庭・生活
- **視覚的識別**: フォームやリストでカテゴリを色とアイコンで識別

#### 🔧 カテゴリ管理機能
- **設定からアクセス**: 設定 → カテゴリ管理で簡単アクセス
- **タブ分離表示**: 収入・支出カテゴリを分けて管理
- **編集・削除機能**: 作成済みカテゴリの変更・削除
- **並び替え機能**: ドラッグ&ドロップでカテゴリの順序変更
- **重複防止**: 同名カテゴリの作成を自動的に防止

### 💾 データベース強化

#### 🗄️ 新しいテーブル構造
- **custom_categories テーブル**: カスタムカテゴリ専用テーブル追加
- **自動マイグレーション**: v4データベーススキーマに自動更新
- **重複制約**: 名前とタイプの組み合わせでユニーク制約
- **デフォルトカテゴリ**: 従来のカテゴリをデフォルトカテゴリとして移行

#### 🔄 下位互換性
- **既存データ保持**: 既存の収入・支出データに影響なし
- **レガシーサポート**: 従来のカテゴリシステムとの完全互換
- **段階的移行**: 新旧システムの並行運用

## 🛠️ 技術的改善

- **CustomCategory**: カスタムカテゴリのデータモデル

### 🔧 既存ファイルの拡張

### 🎨 UI/UX改善
- **統合カテゴリ選択**: カスタムとプリセットカテゴリを統合表示
- **視覚的フィードバック**: カテゴリ選択時の色・アイコン表示
- **直感的操作**: ドラッグ&ドロップによる並び替え
- **バリデーション**: 入力値検証とエラーハンドリング

## 🐛 バグ修正・改善

- **非推奨API修正**: `Color.value` → `Color.toARGB32()` への更新
- **withOpacity更新**: `withOpacity()` → `withValues(alpha:)` への対応
- **静的解析クリーン**: 全ての分析警告・エラーを解消
- **未使用コード削除**: 不要な変数・フィールドの削除

### 🔒 データ整合性
- **重複データ防止**: データベースレベルでの重複制約
- **エラーハンドリング**: 例外処理の強化
- **トランザクション管理**: データベース操作の原子性保証

## 🚀 ユーザーエクスペリエンス

### 📋 使用方法
1. **設定 → カテゴリ管理**でカテゴリ管理画面を開く
2. **収入**または**支出**タブを選択
3. **+ボタン**で新しいカテゴリを作成
4. **カテゴリ名、色、アイコン**を設定
5. **支出・収入入力時**に作成したカテゴリを選択

### 🎯 改善されたワークフロー
- **個人化**: 個人の支出・収入パターンに合わせたカテゴリ作成
- **詳細分析**: より細かいカテゴリ分けによる家計分析
- **視認性向上**: 色とアイコンによる直感的なカテゴリ識別
